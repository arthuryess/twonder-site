# Twonder public support site

Static support and privacy pages for Twonder, hosted on GitHub Pages.

- Support URL: https://arthuryess.github.io/twonder-site/
- Privacy Policy URL: https://arthuryess.github.io/twonder-site/privacy.html
- Optional Marketing URL: the Support URL (or leave blank).
- App terms: Apple's standard EULA, linked from the support page.

Publish from the main branch, repository root. No build step, analytics, cookies, or external assets. Keep policy text synchronized with the app's actual behavior. This repository contains no Flutter app source or credentials.
